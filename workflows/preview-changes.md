# Workflow: Preview Changes — Edu-BanhMiMaHai OS

## Overview
Cung cấp bản xem trước chi tiết (Git diff + hướng dẫn chạy local server) trước khi đưa các chỉnh sửa vào file chính thức.

## Instructions
1. **Hiển thị Diff Block**: Xuất rõ các dòng thêm mới (`+`) hoặc loại bỏ (`-`).
2. **Local Server Instruction**:
   Cung cấp lệnh chạy máy chủ web thử nghiệm:
   ```bash
   python -m http.server 8000
   ```
   Địa chỉ truy cập thử nghiệm: `http://localhost:8000/hoinhap/`
3. **Checklist Xem Trước**:
   - [ ] Giao diện hiển thị đúng trên di động và máy tính.
   - [ ] Các câu hỏi và đáp án hiển thị rõ ràng, không bị lỗi font hay mất ký tự.
   - [ ] Các nút bấm tương tác bình thường.
