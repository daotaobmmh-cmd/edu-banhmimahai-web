## 2. Chi tiết bản quyền từng font

### 2.1. Quicksand
- **Tác giả / Nhóm dự án:** Andrew Paglinawan, Thomas Jockin, Bonnie Shaver-Troup
- **Kho lưu trữ chính:** [google/fonts/ofl/quicksand](https://github.com/google/fonts/tree/main/ofl/quicksand)
- **Giấy phép:** SIL Open Font License, Version 1.1
- **Quyền sử dụng:** Miễn phí 100% cho mục đích cá nhân và thương mại.

### 2.2. Be Vietnam Pro
- **Tác giả / Nhóm dự án:** Lâm Bảo, Tony Lê, Việt Anh Nguyễn (Yellow Type Foundry)
- **Kho lưu trữ chính:** [bettergui/BeVietnamPro](https://github.com/bettergui/BeVietnamPro)
- **Giấy phép:** SIL Open Font License, Version 1.1
- **Quyền sử dụng:** Miễn phí 100% cho mục đích cá nhân và thương mại.
- **Lưu trữ local:** File font local `scratch/fonts/be_vietnam_black.ttf` và `be_vietnam_extrabold.ttf` được đi kèm file văn bản `scratch/fonts/OFL.txt`.

### 2.3. Material Symbols Outlined
- **Tác giả:** Google LLC
- **Giấy phép:** Apache License, Version 2.0
- **Quyền sử dụng:** Miễn phí cho mục đích web và thương mại.

## 3. Cam kết quy chuẩn Zero-Trust
- Không sử dụng font từ các nguồn trôi nổi, Việt hóa lậu (`iCiel`, `SVN`, v.v.).
- Không sử dụng font ghi rõ *"Personal Use Only"* hoặc *"Demo"*.
- Tất cả font nhúng web đều lấy trực tiếp từ hạ tầng uy tín Google Fonts CDN (`https://fonts.googleapis.com/...`).
